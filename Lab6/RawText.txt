Создание простых и материализованных представлений БД «Кинотеатр»Для проектируемой базы данных кинотеатра (CinemaDB) были сформированы три простых представления и два материализованных представления, обеспечивающих удобный доступ к операционной аналитике.1. Простые представления (Views)Представление 1 (vw_active_preorders): Отображает информацию об активных и выкупленных бронированиях с контактными данными клиентов.SQLCREATE VIEW vw_active_preorders AS
SELECT 
    p.id_preorder,
    c.fio AS client_name,
    c.phone AS client_phone,
    p.booking_datetime,
    p.status
FROM Preorders p
JOIN Clients c ON p.id_client = c.id_client;
Представление 2 (vw_session_details): Содержит расширенную информацию о сеансах, включая наименование фильма, жанр, название зала, базовую стоимость и количество проданных билетов.SQLCREATE VIEW vw_session_details AS
SELECT 
    s.id_session,
    m.title AS movie_title,
    m.genre AS movie_genre,
    h.name AS hall_name,
    s.session_datetime,
    s.base_price,
    COUNT(t.id_ticket) AS tickets_sold
FROM Sessions s
JOIN Movies m ON s.id_movie = m.id_movie
JOIN Halls h ON s.id_hall = h.id_hall
LEFT JOIN Tickets t ON s.id_session = t.id_session
GROUP BY s.id_session, m.title, m.genre, h.name, s.session_datetime, s.base_price;
Представление 3 (vw_ticket_sales): Детализирует каждый проданный билет с указанием сотрудника, оформившего продажу, и статуса брони.SQLCREATE VIEW vw_ticket_sales AS
SELECT 
    t.id_ticket,
    m.title AS movie_title,
    s.session_datetime,
    e.fio AS employee_name,
    e.role AS employee_role,
    COALESCE(p.status, 'без брони') AS booking_status,
    t.row_num,
    t.seat_num,
    t.actual_price
FROM Tickets t
JOIN Sessions s ON t.id_session = s.id_session
JOIN Movies m ON s.id_movie = m.id_movie
JOIN Employees e ON t.id_employee = e.id_employee
LEFT JOIN Preorders p ON t.id_preorder = p.id_preorder;
2. Материализованные представления (Materialized Views)Материализованное представление 1 (mv_movie_revenue_stats): Фиксирует физически на диске сводную статистику по проданным билетам и общей выручке для каждого фильма.SQLCREATE MATERIALIZED VIEW mv_movie_revenue_stats AS
SELECT 
    m.id_movie,
    m.title AS movie_title,
    m.genre AS movie_genre,
    COUNT(t.id_ticket) AS total_tickets_sold,
    COALESCE(SUM(t.actual_price), 0) AS total_revenue
FROM Movies m
LEFT JOIN Sessions s ON m.id_movie = s.id_movie
LEFT JOIN Tickets t ON s.id_session = t.id_session
GROUP BY m.id_movie, m.title, m.genre;
Материализованное представление 2 (mv_employee_performance): Кэширует показатели эффективности работы кассиров (количество обслуженных билетов и суммарную выручку).SQLCREATE MATERIALIZED VIEW mv_employee_performance AS
SELECT 
    e.id_employee,
    e.fio AS employee_name,
    e.role AS employee_role,
    COUNT(t.id_ticket) AS tickets_processed,
    COALESCE(SUM(t.actual_price), 0) AS total_sales_amount
FROM Employees e
LEFT JOIN Tickets t ON e.id_employee = t.id_employee
GROUP BY e.id_employee, e.fio, e.role;
2.2. Запросы к представленияма) Запрос на выборку, содержащий вложенный запросФормулировка: Из материализованного представления mv_movie_revenue_stats выбрать фильмы, суммарная выручка от продажи билетов на которые превышает среднюю выручку по всем фильмам кинотеатра.SQL-скрипт:SQLSELECT 
    id_movie,
    movie_title,
    movie_genre,
    total_tickets_sold,
    total_revenue
FROM mv_movie_revenue_stats
WHERE total_revenue > (
    SELECT AVG(total_revenue) 
    FROM mv_movie_revenue_stats
)
ORDER BY total_revenue DESC;
