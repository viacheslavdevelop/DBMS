# Задание к расчетно-графической работе по дисциплине «Системы управления базами данных»

## Вариант 17. Создать базу данных автоматизации учёта и прогноза запасов нефтепродуктов, реализуемых нефтебазой.

## Примерное содержание расчетно-графической работы (РГР)

1. Краткое описание примерной области.
2. Концептуальное проектирование БД.
3. Логическое проектирование БД.
4. Реализация БД в СУБД PostgreSQL.
5. Разработка запросов к БД.
6. Разработка объектов БД.

---

## Порядок выполнения работы

1. Выбрать индивидуальный вариант БД (см. `Темы РГР_СУБД.pdf`), который определяется порядковым номером студента в общем списке группы.
2. В тексте РГР описать предметную область БД, указав бизнес-правила, сущности, атрибуты.
3. Спроектировать структуру БД в нотации IDEF1X. Вставить скрин и указать программную среду разработки нотации IDEF1X.
4. Выполнить и описать нормализацию БД.
5. Реализовать БД в СУБД PostgreSQL (не менее 5 таблиц). Выбрать названия, типы полей, создать диаграмму БД. В текст РГР вставить SQL-скрипты, при этом указав специфику языка БД (например, DDL).
6. Создать индексы.
7. Заполнить таблицы данными (не менее 15 записей).
8. Разработать запросы к БД (таблица 1). В тексте РГР представить формулировки запросов, SQL-скрипты и скрины, фиксирующие выполнение SQL-запроса.
