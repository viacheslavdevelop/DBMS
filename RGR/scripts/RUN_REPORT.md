## 7. Замечания

- В документе указан PostgreSQL 16; фактически использован PostgreSQL 18.6.
  Несовместимости не обнаружено: все конструкции (PL/pgSQL, `LATERAL`,
  `REFRESH MATERIALIZED VIEW CONCURRENTLY`, `ON CONFLICT`, `make_interval`)
  поддерживаются.
- `00_create_database.sql` удаляет и заново создает только `oil_depot_db`.
  Ранее существовавшая база `oildepotdb` не затрагивалась.
- Порядок `03_seed_data.sql` → `08_triggers.sql` обязателен: тестовые остатки
  заложены в `storage_tanks`, и триггеры пересчета при наполнении срабатывать
  не должны. В `run_all.sh` этот порядок соблюден.
- В запросе 3.2 отрицательные значения `days_to_min` у РВС-02, РВС-04, РВС-09,
  РВС-12 — ожидаемый результат: страховой запас уже ниже нормы по прогнозу,
  это не ошибка.
- Логи выполнения: `scripts/logs/*.log`. Ошибок в логах нет.
- Повторный запуск `./run_all.sh` также завершился с кодом 0: скрипт `00`
  корректно удалил существующую БД и развернул ее заново, что подтверждает
  воспроизводимость и идемпотентность набора.
